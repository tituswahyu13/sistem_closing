  • 1. Set maintenance mode (OFFLINE = 0)
  • 2. Backup penuh DB simpadu ke format .sql.gz

  • 4. Truncate & sinkronisasi data tagihan ke pdam.ppob
  • 5. Pembebasan/pelunasan otomatis golongan rumah ibadah
  • 6. Mengembalikan status database ke Online (OFFLINE = 1)
